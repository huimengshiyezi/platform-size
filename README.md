# 平台尺寸助手

一个**纯前端、免安装、图片不上传**的「平台尺寸」小工具：先查各平台的图片尺寸，再把自己的图按尺寸裁好，最后一次导出一整套。

全部处理都在你自己的浏览器里完成 —— 无后端、无统计、无联网请求，**断网也能用**。

## 三个区块

### ① 尺寸速查表

一条一条查「哪个平台、什么用途、多少像素、什么比例、要注意什么」。

- 覆盖 **9 个平台**：公众号、小红书、抖音、视频号、B站、知乎、微博、今日头条、快手
- **共 50 条**常见用途：封面、首图、次图、头像、竖版长图、横版视频封面、主页横幅、商品主图……
- 每条都写清 **像素尺寸 + 比例 + 一句注意事项 + 数据口径**
- 顶部有**搜索框**（按平台名或用途关键词过滤）和**平台筛选**按钮
- 每条右边的「**用这个尺寸裁切 →**」会把平台、用途、尺寸一起带到第 ② 区块

### ② 按尺寸裁切

- 上传一张图：**点击选择**、**拖进去**、或直接 **Ctrl + V 粘贴**
- 显示原图信息：文件名、像素、体积、比例
- 画布实时预览裁切结果
- **锚点**五选一：居中 / 顶部 / 底部 / 左中 / 右中
- **放大滑块**（1.0× ~ 4.0×）：100% 是按目标比例能裁到的最大范围；往右拉是「先放大再裁」，画面更满，但原图小的时候会发虚
- **常用比例快捷键**：1:1、3:4、4:3、9:16、16:9、2.35:1
- 导出 **PNG** 或 **JPG**（JPG 可选质量 40~100）
- 导出前后都会显示预计体积 / 实际体积

### ③ 一图多出

- 勾选多个平台尺寸，一次从同一张原图裁出多张
- 两种出货方式：
  - **打包成一个 ZIP**（推荐，不会被浏览器拦截）
  - **逐个下载**（浏览器可能弹窗问「是否允许多个下载」，点允许即可）
- 带进度条、逐条结果和体积，单条失败不影响其他条

## 尺寸数据从哪来（重要）

- 数据**全部内嵌在 `index.html` 里**，不联网、不请求任何接口。
- 每条数据的「口径」字段写明来源强度，只有三种：
  | 口径 | 含义 |
  |---|---|
  | 后台常见推荐值 | 平台后台确实提示过的推荐尺寸 |
  | 常见值，以平台后台为准 | 社区与后台都常见的写法，但平台会调整 |
  | 通用常见值 | 全行业通用（如竖屏 1080×1920、横屏 1920×1080） |
- **平台规则会变**：本工具里的数字是「参考值」，正式投放前请以各平台后台的提示为准。
- 找不到理想尺寸？用自定义宽高输入，或按比例快捷键换算即可。

## 已知限制

- **不支持 HEIC/HEIF**（iPhone 默认照片格式）：浏览器解不了，请先转成 JPG 或 PNG
- **GIF 只取第一帧**，不做动图裁切
- 原图带 EXIF 旋转信息时，现代浏览器一般会自动摆正；若发现方向不对，请先在系统看图工具里转正再上传
- **放大倍数只能 ≥ 1.0**：本工具只做「放大后裁切」，不做「缩小后补白边」
- 导出的像素尺寸等于你填的目标尺寸；目标比原图大时会被拉伸，界面会给出提醒
- 「逐个下载」一次导出很多张时，浏览器可能拦截，建议用 ZIP 打包
- `file://` 下双击打开时，部分浏览器的「另存为」行为略有差异，导出文件一律进「下载」文件夹

## 开发者备注

- 单文件结构，改尺寸数据只需改 `index.html` 里的 `SIZES` 数组（字段：`p` 平台 / `u` 用途 / `w` 宽 / `h` 高 / `n` 注意事项 / `s` 口径）
- 纯计算部分（比例文字、裁切矩形、CRC32、ZIP store 打包）用 `/*==CORE-START==*/` 标记包起来，**不碰 DOM**，可以直接抽出来做单元测试
- ZIP 打包是自己实现的 store 模式（零依赖），带 UTF-8 文件名标记，中文文件名不会乱码
